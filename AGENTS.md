# Repository instructions

These instructions apply to the entire Codex Armada repository.

- Write all code, documentation, tests, commit messages, and user-facing output in English.
- Preserve Python 3.11 compatibility and zero third-party runtime dependencies.
- Keep fail-closed behavior for routing, source integrity, scope, approval, verification, and acceptance.
- Never add automatic push, pull-request creation, merge, deployment, secret rotation, or destructive production behavior.
- Do not vendor Luna Forge. Integrate it only through an exact Git source pin and upstream validation.
- Update tests, public documentation, metrics, changelog, and rollback notes with behavior changes.
- Do not weaken local JSON Schema validation or trust model completion claims without repository evidence.
- Use focused Conventional Commit messages. Never push automatically.
