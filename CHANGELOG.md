# Changelog

All notable changes to Codex Armada are documented here.

## 1.0.0 — 2026-08-05

### Added

- Public, general-purpose Codex orchestration control plane with no product-specific policy.
- Risk-aware routing across GPT-5.6 Luna, Terra, and Sol.
- Four profiles: economy, balanced, quality, and critical.
- Durable run and task state outside target repositories.
- Isolated worktree execution, focused local task commits, and safe cherry-pick application.
- Explicit ownership, protected-path, symbolic-link, deletion, and production-change gates.
- Local JSON Schema validation for all planner, worker, reviewer, probe, and canary outputs.
- Runtime model, effort, sandbox, permission-profile, and token-usage attestation from Codex events.
- Deterministic verification command parsing and repository-mutation detection.
- Risk-based commitment and final review gates.
- Budget estimation and observed-token credit accounting.
- JSON and standalone HTML evidence reports.
- Doctor, canary, benchmark, resume, verification, and interactive wizard workflows.
- Direct integration with Luna Forge 2.2.1 from a full pinned Git commit.
- Upstream manifest verification, validator execution, project-local installation, backups, and before/after integrity attestation.
- Cross-platform automated tests, packaging, repository validation, security automation, and deterministic release tooling.
- Public documentation, governance, threat model, benchmark protocol, and evidence-class rules.
- Simple tagged release automation that validates the repository, builds a wheel and source artifacts, and publishes one GitHub release.
