# Support

Use the repository's GitHub issue forms for reproducible bugs and feature proposals.

Before filing a bug, collect:

```bash
codex-armada version
python --version
git --version
codex --version
codex-armada --repo /path/to/project --json doctor
```

Redact private paths, repository content, prompts, tokens, and credentials. Attach a minimal disposable repository whenever possible.

Questions about Luna Forge itself belong in the [Luna Forge repository](https://github.com/RealAhmedOsama/Luna-Forge) unless the problem is specific to Codex Armada's fetch, validation, installation, routing, or attestation behavior.
